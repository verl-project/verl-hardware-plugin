How to produce a timeline log

Set VERL_TPU_TIMELINE=1 in the job's runtime env of a TPU run with verl-hardware-plugin. The plugin's TPU trainer engine, its tpu-sync weight sync and its vLLM rollout server then print one VERL_TIMELINE{...} line per finished span, which Ray forwards into the job log, so the plain job log is all this page needs (no verl change; the trainer-loop phases are rebuilt from the timing_s/* step metrics, anchored at each step's weight sync):

ray job submit ... --runtime-env-json '{"env_vars": {"VERL_TPU_TIMELINE": "1", ...}}' -- bash examples/tpu/grpo/run_qwen3_4b_torchtitan.sh
ray job logs --address http://localhost:8265 <submission-id> > job.log      # then drop job.log here
python3 -m verl_hardware_plugin.accelerators.tpu.profilers.make_report job.log -o report.html --summary   # sharable copy

Lanes. trainer loop (driver): step, then gen = waiting for the replay buffer (i.e. for rollout), old/ref log-prob, advantage, update, update_weights with its sync.* phases (exact, printed by the weight sync) and testing = validation; the other phases are laid out from timing_s/*. trainer ranks: what trainer rank 0 executes on its chips (update_actor = forward/backward + optimizer step, compute_ref_log_prob = reference forward, update_weights = weight-sync gather / bind / device-to-host staging); gaps are idle chips. rollout replica N (one per vLLM replica / sampler slice): state (green = generating, light green = still generating while the submission gate is closed for a weight sync, i.e. the sync waits for the rollout to drain, orange = engine paused for the weight transfer/install, red = idle with nothing to generate), weights = the weight version the replica serves (vk = the weights after step k), decoding = requests the engine is running, waiting = requests queued inside the engine (dotted: parked at the closed gate), server = drain / paused and the weight-sync RPCs, and one bar per request while it decodes (teal = ended with EOS, orange = hit the length limit, red = aborted by a weight sync and resumed later; or colored by weight version).
